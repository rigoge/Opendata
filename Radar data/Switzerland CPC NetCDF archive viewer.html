Important: Please note, that radar precipitation data give the precipitation rate in mm/h. If you plot the data, it is conversed to mm (or also known as l/m²) in aspect to the respective time resolution. The official values are the ones measured at the MeteoSwiss stations. Precipitation estimation from radar is prone to error and should be treated as such.

Local multi-day CPC netCDF exports · select a day · animate · point query

This tool works entirely from a locally provided netCDF file (a multi-day CombiPrecip/CPC archive export) — there is no live Open Data fetch here, and only CPC is supported. Load a file below, then pick one of the days found inside it to animate and query.

Load a netCDF file to begin.
Click the map to read the exact grid value under the cursor (nearest cell, no interpolation), and offers a time-series plot + CSV export across the whole selected day at that point.

Values are shown in mm/h. For a full day of hourly data, the precipitation actually fallen in each hour numerically equals the hourly rate, so no extra conversion is applied; the time-series plot/CSV note this explicitly.

Only the netCDF's own x/y (LV95/EPSG:2056) coordinates and its own fill-value/scale/offset metadata are used to interpret the data — nothing is assumed beyond what the file itself declares. Values below 0.1 mm (including exactly 0) and implausibly huge fill-sentinel values are both treated as no-data — shown fully transparent on the map, excluded from the colour scale, and shown as "no data" in the click popup, plot, and CSV. The colour scale itself uses the same fixed classification (0.1/0.3/0.5/1/2/3/5/10/20/30/50/100 mm/h) as the live precipitation viewer.
