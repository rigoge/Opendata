Searches Swiss places, postcodes and addresses using the official geo.admin.ch location service.
Fallback if direct access is blocked by the browser or CORS.
For archived 5min datasets select a folder. They can be animated and viewed if all the files from a day are saved in the same folder.
Exact filter:
BZCyyjjjHHMMvl.845.h5
MZCyyjjjHHMMvl.850.h5, where HHMM is either the 5-minute UTC time, or one of the special daily-sum codes 2400 (00:00–24:00 UTC) or 3000 (06:00–06:00 UTC) — both codes are valid for either product.

Click the map to read the exact pixel value (POH or MESHS) at that location. In 5-minute mode, the popup also offers a time-series plot and CSV export across the whole day at that point.

Data source: MeteoSchweiz / data.geo.admin.ch, CC BY 4.0. When redistributing or reproducing the data, the attribution Source: MeteoSwiss is required. The daily sum covers either 00:00–24:00 UTC or 06:00–06:00 UTC, depending on which code (2400/3000) is present for that day; the code YYDDD directly identifies that calendar day.
for detailed information about the POH und MESHS Products see https://opendatadocs.meteoswiss.ch/d-radar-data/d3-hail-radar-products
