Swiss surface climate grid viewer

Precipitation, temperature, sunshine – spatial climate analyses · 1961–present

Data source: ch.meteoschweiz.ogd-surface-derived-grid, item archive-ch. The parameter list below is read directly from that item. Almost all products use the Swiss LV95/EPSG:2056 grid; a few (the pre-1961 reconstructions) use WGS84 directly – this viewer detects which one applies to each file automatically.

Click anywhere on the map to read the exact grid value under the cursor.

The colour scale auto-adjusts to the min/max of whichever parameter and year you load. For temperature, precipitation, and sunshine duration it re-adjusts to each individual frame's own min/max as you step through the animation; other parameters use one fixed range across the whole file. Negative values are treated as no-data (shown transparent); for precipitation and sunshine duration a value of exactly 0 is also shown fully transparent. Each yearly file is animated frame by frame (daily, monthly, or yearly time steps, depending on the parameter).
